Сайт для бьюти-мастера с онлайн-записью

Одностраничный сайт мастера по наращиванию ресниц. Всё работает по-настоящему — это не макет.

  • Онлайн-запись: клиент видит свободные слоты и оставляет заявку с сайта
  • Telegram-бот: уведомление мастеру о заявке, подтверждение визита клиентом, напоминание за 2 часа
  • Приватная аналитика: посетители, источники переходов, страны, время на сайте — сводка в Telegram каждый вечер
  • Инфраструктура: статический сайт + serverless-воркер + база, без постоянного сервера
  • Весь код — свой, с защитой форм, ограничением нагрузки и автотестами
